# Poster Layout Template (44" x 33", landscape)

- Minimum font size: 24 pt
- Recommended sections:
  1. Title + Authors + School
  2. Introduction / Background
  3. Research Question / Hypothesis
  4. Methods
  5. Results (figures + captions)
  6. Discussion
  7. Conclusion / Future Work
  8. References + Acknowledgments

Design tips:
- Keep text concise and use bullet points.
- Use high-contrast colors.
- Ensure figures are readable at 3–4 feet away.
